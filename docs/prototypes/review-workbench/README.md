# 审图工作台 · 静态版面原型

> 历史原型：已由真实工作台及后续UI修正替代，不再独立安排U系列验收。当前未完成项见[当前集合](../../../tests/manual/current.md)，产品回归见[回归集合](../../../tests/manual/regression.md)。下方为原型制作时的记录。

仅用于版面审核，包含 HTML、共用 CSS 和本地绘制的 SVG 样稿。没有 JavaScript、API、数据库、浏览器存储或提交行为；普通链接可切换页面，其余按钮均为静态示意。不替换现有 Vue 应用。

## 审核入口

- [审阅工作台](workbench.html)：左侧多图片列表、中间画布、右侧标记，顶部统一保存。
- [图片库](library.html)：多图片卡片与搜索、上传、批量操作占位。
- [保存历史](history.html)：继承链、完整打点画面、本次相对父保存的内容 diff。
- [昵称入口](index.html)：昵称与进入工作台，未加入认证或权限。

可直接用浏览器打开任一 HTML；或在仓库根目录启动独立静态预览：

```powershell
python -m http.server 4180 --bind 127.0.0.1 --directory docs/prototypes/review-workbench
```

打开 [工作台预览](http://127.0.0.1:4180/workbench.html)，顶部导航可切换四个页面。此端口只用于本原型，不改变产品3002/5174默认端口；占用时不自动换端口或停止其他应用。

静态样稿不读取演示包或真实运行数据。后续业务运行/测试通过环境变量 DATA_DIR 分离；本轮没有新增“演示模式”产品开关，没有实现继承版本、userId表或并发协作。

具体人工审核步骤、预期与原因见 [静态原型手动集合](../../../tests/manual/regression.md)。视觉、窄屏、焦点由用户验收，不运行浏览器自动化。若需保存截图证据，仅放项目 tests/.tmp/ 专用目录。
