# 审图打点作业说明

状态：P0–P1 已完成，业务功能待开发
最后更新：2026-10-25

## 项目说明

本项目计划实现一个本地优先、可在可信局域网共享的图片审阅 Web 工作台。最终目标是上传图片、点击创建问题标记、填写并保存说明，再次打开查看同一位置的标记。目前仅完成 P0–P1：工程骨架、服务状态页、SQLite 初始化、开发和生产启动；图片业务尚未实现。

前端使用 Vue 3 + TypeScript，后端使用 Node.js + TypeScript，数据库使用本地 SQLite。图片原文件由应用保存到本地数据目录，SQLite 保存图片元数据、标注和操作人记录。

## 需求假设

详见 [设计基线](design.md)。主要约定：

- 支持多张图片和多个标记。
- 标记可以编辑和删除。
- 图片可以放大、缩小和滚动。
- 标记坐标使用归一化值。
- V1 使用昵称和操作人 ID，不做完整账号。
- 支持本机访问，并可配置为可信局域网访问。
- V1 不做实时协作；V2 规划增加基础 WebSocket 更新通知。
- 不做公网部署、生产 HTTPS 和复杂权限。

## 已知限制

当前已知限制：

- 昵称和操作人 ID 不是安全认证。
- 局域网模式依赖运行服务的电脑持续在线。
- V1 不提供实时标记推送。
- V1 不支持公网安全部署。
- SQLite 适合本作业规模，不承诺高并发生产能力。
- P0–P1 状态页之外的图片、标记、昵称和协作功能尚未实现；后端源码修改后需要重启开发命令。
- Windows ACL 拒写未单独实机演练；目录写入失败已通过真实失效目录和文件占位验证，不能据此宣称所有磁盘/权限故障均通过。

实现过程中新增的限制必须同步到此处。
