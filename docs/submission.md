## 已知限制

当前已知限制：

- 昵称和操作人 ID 不是安全认证。
- 局域网模式依赖运行服务的电脑持续在线。
- SSE只通知已提交更新，不广播输入、光标或编辑状态，不保证每条通知持久回放；连接恢复通过GET对账，写入安全依赖版本条件。
- V1 不支持公网安全部署。
- SQLite 适合本作业规模，不承诺高并发生产能力。
- 多图片列表、搜索/排序/分页、切换与链接、批量上传、整图删除与P6核对/更新通知已实现；上传队列只保留在内存，不承诺刷新续传或服务端取消。账号权限、编辑软锁、自动保存、字段级合并和离线同步队列未纳入当前交付；M6局域网延期。
- 同名新上传是独立imageId，不替换旧原图或迁移旧坐标；审阅revision不是原图版本。整图删除清理回执，不能保证随后旧重试仍能证明此前保存发生；旧请求不恢复图片。合并连同待删除项超过500条时先拒绝应用并保留原草稿，需要减少新增后再核对。
- 普通关闭新开不恢复未保存输入，标签页缓存失败与后端保存失败分别提示；不承诺浏览器强退/断电恢复。旧 P3 图片缓存不承诺关闭瞬间物理擦除，不能描述为安全销毁。服务器拒绝动画及非正常 EXIF 方向；后端源码修改后需重启开发命令。
- ENOSPC 只做故障注入，物理磁盘耗尽/断电未实机演练；文件系统与 SQLite 不是跨资源原子事务，启动扫描只清理确认无引用且超过 24 小时的本应用文件，不能代替备份。
- Windows ACL 拒写未单独实机演练；目录写入失败已通过真实失效目录和文件占位验证，不能据此宣称所有磁盘/权限故障均通过。

实现过程中新增的限制必须同步到此处。
