# P3 单图多标记与视图交互验收计划

状态：P3 已实现，以下页面交互待用户执行；本轮未运行浏览器自动化或逐项人工验收。

## 自动化覆盖计划

已在 tests/unit/ 覆盖实际调用的纯逻辑/状态模型；覆盖边界如下，实际结果见 ../README.md：

- 坐标：10%/100%/400%、正负视口偏移和模拟滚动后的矩形、四边及四角；留白、零尺寸和非有限值拒绝；归一化 → 像素 → 归一化往返误差。
- 视图：宽图/竖图/小图适应、不超过 100%、适应可低于 10%；手动边界和 25 个百分点步进；中心锚点、定位与滚动边界钳制；容器变化下两种视图模式。
- 集合：连续新增、非法说明不入集合、取消、编辑副本隔离/应用/还原、选中和删除、标签不重排不复用、稳定 ID、同位置多条可分别操作。
- 展开与内存：多条独立展开、不重复记录展开 ID、收起/再展开保留原说明与编辑草稿、删除清理对应展开状态。
- 标签页恢复：可校验的状态快照与标签计数、图片 Blob 关联、刷新重建适配器、独立空会话不恢复、缓存写入失败/配额失败与重试、旧写入不能覆盖新图、清除不能被异步写入复活。storage/Blob adapter 为注入替身，不等于实际浏览器缓存验收。
- 草稿保护：无修改/新草稿/编辑修改三种状态；应用、放弃、留下；非法草稿、动作仅执行一次、确认期间后续动作不越过保护；删除编辑条目的一次确认。
- 预览生命周期：换图取消/失败保留完整审阅状态、成功才重置；选择竞态、清除/卸载中断和 URL 清理；P2 原有文件预检边界继续回归。

自动化仅证明纯逻辑与可注入状态流，不证明 DOM 布局、真实滚动、SVG 事件、焦点、原生离开提示或浏览器解码。继续使用 Vitest / Supertest，不使用浏览器自动化或替代工具。

## 手动准备

以下命令由用户执行，本轮没有启动供人工验收的实例。使用新的项目终端，确认 cwd 为本仓库：

```powershell
$env:HOST = '127.0.0.1'
$env:PORT = '3002'
$env:VITE_PORT = '5174'
$env:DATA_DIR = Join-Path (Get-Location) 'tests/.tmp/manual-p3/data'
New-Item -ItemType Directory -Force -Path tests/.tmp/manual-p3/fixtures | Out-Null
npm run dev
```

打开 [开发页面](http://127.0.0.1:5174)。端口冲突时核对占用者，不停止其他应用；按需显式设置 PORT/VITE_PORT，代理跟随。这里只停止自己启动的测试实例。

将自有静态 PNG/JPEG/WebP **副本**放在 tests/.tmp/manual-p3/fixtures/：一张约 2000×1500 且包含明确网格/十字目标的图、一张竖图、一张小图、一张长文件名图片；均须符合 20 MiB、各边 12000、4000 万总像素限制。另准备文本内容伪装成 broken.png 的文件用于解码失败。可用系统画图手工制作网格图，不覆盖原文件；不要使用真实用户 DATA_DIR。

```powershell
$projectRoot = (Resolve-Path -LiteralPath '.').Path
if (-not (Test-Path -LiteralPath (Join-Path $projectRoot 'tests/manual/p3.md'))) { throw 'Run in the project root' }
$manualTarget = [IO.Path]::GetFullPath((Join-Path $projectRoot 'tests/.tmp/manual-p3'))
$allowedParent = [IO.Path]::GetFullPath((Join-Path $projectRoot 'tests/.tmp')) + [IO.Path]::DirectorySeparatorChar
if (-not $manualTarget.StartsWith($allowedParent, [StringComparison]::OrdinalIgnoreCase)) { throw 'Cleanup target outside tests/.tmp' }
if (Test-Path -LiteralPath $manualTarget) { Remove-Item -LiteralPath $manualTarget -Recurse -Force }
'HOST','PORT','VITE_PORT','DATA_DIR' | ForEach-Object { Remove-Item -LiteralPath "Env:$_" -ErrorAction SilentlyContinue }
```
