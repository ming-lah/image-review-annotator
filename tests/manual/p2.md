## 准备

在项目根目录用 PowerShell 启动隔离实例。端口占用时先核对占用者；不要停止其他应用，可显式覆盖 PORT/VITE_PORT。

```powershell
$env:HOST = '127.0.0.1'
$env:PORT = '3002'
$env:VITE_PORT = '5174'
$env:DATA_DIR = Join-Path (Get-Location) 'tests/.tmp/manual-p2/data'
New-Item -ItemType Directory -Force -Path tests/.tmp/manual-p2/fixtures | Out-Null
node --input-type=module -e "import fs from 'node:fs'; const png=Buffer.from('iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR4nGNQ8XP4DwAC/gGyl0WqjgAAAABJRU5ErkJggg==','base64'); const dir='tests/.tmp/manual-p2/fixtures/'; fs.writeFileSync(dir+'tiny.png',png); fs.writeFileSync(dir+'broken.png','not an image'); fs.writeFileSync(dir+'empty.png',''); fs.writeFileSync(dir+'unsupported.txt','text'); fs.writeFileSync(dir+'oversized.png',Buffer.alloc(20*1024*1024+1));"
```

打开 [开发页面](http://127.0.0.1:5174)。除上述文件，将自己可正常打开的静态 PNG/JPEG/WebP 图片各复制一张到 fixtures；用宽图、竖图和长文件名补充布局测试。所有试验副本仅放在 tests/.tmp/manual-p2/，不要使用默认用户 DATA_DIR。

## 验收条目

| 编号 | 操作步骤 | 预期结果 | 测试原因 |
|---|---|---|---|
| P2-M1 空态和取消选图 | 首次打开，确认提示；打开文件选择器后取消 | 显示尚未选择图片、仅临时未保存；取消不改变状态 | 避免把本地草稿误解为已经上传或保存 |
| P2-M2 图片预览 | 分别选择准备好的 PNG/JPEG/WebP 和 tiny.png | 正确显示文件名、像素尺寸；等比适应容器；小图不出现无谓拉伸；不出现上传成功提示 | 图片解码与布局需要真实浏览器确认 |
| P2-M3 坐标和重复点击 | 在横图/竖图中选中心及靠近四边位置，每次取消后再换位置；再点图片外的留白；已有点时点另一处 | 点与实际点击位置一致，容器宽度变化后仍在同一图片位置；留白无标记；已有草稿不被第二次点击移动，提示先取消 | 核对实际 img 尺寸、留白与 SVG 的坐标一致性；边缘标记不应被裁掉 |
| P2-M4 说明与取消 | 新建点，输入空格、普通中文、2000/2001 个字符及 `<script>alert(1)</script>`；点击取消草稿 | 显示待填写/有效未保存/过长；文本原样进入输入框，不执行脚本；取消同时移除点和说明 | 校验规则、中文输入、纯文本安全和状态反馈 |
| P2-M5 替换确认与恢复 | 填写草稿，选择另一图，先取消放弃确认；再次选择 broken.png 并确认；随后选正常图并确认；最后清除预览 | 取消确认保留图和说明；解码失败仍保留原图和草稿且有中文错误；成功替换才清除旧草稿；清除返回空态，带草稿时先确认 | 避免替换失败导致用户输入丢失，验证可恢复性 |
| P2-M6 非法文件 | 依次选择 empty.png、oversized.png、unsupported.txt、broken.png；如文件选择器过滤，切为“所有文件”；随后重选正常图 | 分别提示空文件/超过 20 MiB/类型不支持/无法解码；已有可用图片保持；重选正常图成功，错误消失 | 确认文件输入、提示与实际解码失败链路；MIME 预检不等于服务端安全校验 |
| P2-M7 快速选择 | 连续选择两张较大的有效图片；读取中点击清除预览；再选正常图 | 最后选择优先，无旧图回跳；清除后不恢复旧请求结果；之后可正常使用 | 验证真实加载时序，补充状态机单元测试边界 |
| P2-M8 窄屏与键盘 | 在 1280×800、860×700、375px 宽视口测试长文件名和长说明；Tab 聚焦图片后 Enter/Space，再 Tab 到说明输入 | 页面和表单无横向溢出，图片不变形，焦点清楚；键盘在中心建点，已有点保持原位置 | 布局与键盘事件不由单元测试代替，需人工检查 |
| P2-M9 临时状态与请求 | DevTools Network 开启 Preserve log，选图/打点/输入；刷新页面；选图后将 DevTools 切 Offline，点击重新检查 | 本地审阅没有新增业务 API 请求；刷新恢复空态；服务显示不可用时仍能本地选图打点；恢复 Online 后可重新检查 | 确认未持久化边界、纯本地能力与服务状态独立 |
| P2-M10 生产交付 | Ctrl+C 停开发；同终端 npm run build，再 npm run start；打开 3002 重做 M2–M5 | 仅 Node 服务即可完成相同临时预览流程；不依赖 Vite | 补充真实构建页面、浏览器 Blob URL 和交互的交付验证 |

正式格式签名、动画/EXIF 方向拒绝、服务端上传限额留至 P4；本集合不宣称验证这些能力。
